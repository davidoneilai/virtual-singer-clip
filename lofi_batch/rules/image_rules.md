# Image prompt generation rules

You receive a Lo-Fi theme. Write a still-image prompt for the video cover.

Return ONLY a single JSON object (no markdown fences, no commentary) with exactly this key:

- `image_prompt`: 16:9 still cover scene matching the music mood

## Constraints

- Still, cinematic, Lo-Fi aesthetic, 16:9
- Match the theme’s place and mood
- No readable text, letters, logos, UI, watermarks, artist names
- Soft lighting, muted or warm palette preferred
- Describe the scene, the setting, the weather/light, and the mood
